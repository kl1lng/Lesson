# PhysLab: дизайн-система

**Идея:** лабораторный блокнот на светлой клетчатой бумаге + латунные приборы. Не неон и не «sci-fi HUD»: доска в классе, читаемость с последней парты важнее эффектов.

- Палитра: электрический синий (brand-600, действия), латунь (accent-600, подсказки и баллы), заряды: оранжево-красный «+» и тёмно-синий «−» (формой и знаком, не только цветом).
- Нейтрали: тёплый бумажный фон `#f5f3ec`, сетка 28 px, чернила `#14213d`.
- Шрифт: системный Segoe UI (работает офлайн, совпадает с презентациями NotebookLM). Крупно: 18 px база, 1.7–2.2 rem заголовки.
- Форма: радиусы 10/16/24, мягкие тени, стекло и латунь в SVG-градиентах.
- Движение (только transform/opacity): пружина листочков электроскопа (недодемпфирована, живая), перелёт электронов по траектории, вспышка при касании, плавное появление слайдов, shake при ошибке. `prefers-reduced-motion` отключает анимации.
- Доступность: контраст ≥ 4.5:1, видимый фокус, skip-link, aria-текст на всех SVG, управление клавиатурой, цели касания ≥ 40 px.
- Темы: светлая по умолчанию, тёмная `data-theme="dark"` (те же имена токенов).
