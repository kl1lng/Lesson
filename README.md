# PhysLab · Электростатика

Интерактивный урок физики для электронной доски (8 класс, «Проводники и диэлектрики») на чистом HTML, CSS и JavaScript.
Без сборки, без зависимостей, без интернета: откройте `index.html` двойным щелчком или выложите папку на любой статический хостинг.

## Что внутри
- **Лаборатория 1.** Цепь с лампочкой: образцы между клеммами X и Y, лупа показывает электроны и ионы внутри материала.
- **Лаборатория 2.** Электроскоп: потереть палочку, перетащить к шарику, коснуться предметами; режимы «лишние заряды / все заряды / скрыть» (идея из PhET «Шарики и статическое электричество»).
- **Электризация влиянием** по пяти шагам с анимацией перетекания электронов в землю.
- **Лаборатория 3.** Ряд электризации трением (ряд Фарадея).
- Задания с автопроверкой (порядок шагов, выбор, сортировка), дескрипторы, подсчёт баллов (2 + 6 + 2 = 10), цели урока и возврат к ним, выходной билет.
- Таймер 10 + 30 + 5 минут, режим учителя с ответами (клавиша `T`), тёмная тема, звук зарядов (по кнопке), печать.

Клавиши: `←` `→` листать, `T` ответы учителя, `F` весь экран.

## Физическая модель электроскопа
Сохраняется суммарный заряд N. Поднесённое заряженное тело разделяет заряды (индукция), листочки получают (N/2 + p)/2 каждый,
шарик со стержнем (N/2 − p). Заземление уводит заряд так, чтобы листочки стали нейтральными: N = −2p. Единицы условные.

## Работа класса: сессия, ссылка, доска (как Kahoot / Quizizz)
1. **Учитель** открывает `teacher.html`, входит по ключу, выбирает класс и жмёт **«Создать новую сессию»**. Появляется ссылка для учеников вида `http://адрес/student.html?c=XXXXX` и код. Копируете ссылку, сокращаете в любом сервисе коротких ссылок и отправляете ученикам.
2. **Экран для доски:** кнопка «Открыть экран для доски» (`board.html?c=XXXXX`). Сначала лобби: **QR-код**, адрес, код и имена учеников, которые заходят (всплывают по одному). QR генерируется прямо в браузере (`js/qr.js`, без интернета и библиотек) и ведёт на ту же ссылку.
3. **Ученики** открывают ссылку, вводят имя и ждут в лобби. Одинаковые имена в одной сессии запрещены.
4. Учитель жмёт **«Начать урок»** (на экране доски или на странице учителя). Ученики решают задания в своём темпе, проверка идёт на сервере, у каждого в углу очки и место.
5. На доске живая таблица: строки меняются местами, очки считаются с анимацией, полоса показывает, сколько заданий выполнено.
6. **«Завершить и показать итоги»**: пьедестал с конфетти и список остальных. Ученики на своих экранах видят свою позицию.

Страницы: `index.html` урок для доски (работает без сервера), `student.html` ученик, `teacher.html` учитель (сессии, ответы, оценка по дескрипторам, CSV), `board.html` экран результатов.

Очки: проверка понимания 100, сортировка по 10 за предмет (−5 за ошибку), шаги в заданиях 1 и 2 до 200 каждое, выбор в задании 3 — 100; за ответы, которые проверяет учитель (этап 1, объяснение в задании 3, этап 3), ещё по 100 за балл. Школьная оценка до 10 баллов считается отдельно и видна учителю.
Ключи ответов лежат только на сервере (`server/server.py`), в страницах учеников их нет.

### Запуск в классе (без интернета, на ноутбуке учителя)
```
python server/server.py
```
В окне появится адрес страницы учителя и ключ учителя (он сохраняется в `data/teacher.key`); ссылку для учеников создаёт страница учителя.
Ученики подключаются к тому же Wi-Fi. Нужен только Python 3.8+ (больше ничего ставить не надо). Своё: `python server/server.py --port 9000`, ключ: `TEACHER_KEY=секрет`.
Ответы лежат в `data/physlab.db` (SQLite); не выкладывайте `data/` на GitHub (оно в `.gitignore`).

Проверено локально: создание сессии, вход нескольких учеников, лобби, старт, живая таблица, пьедестал, проверка на сервере, оценка учителем, закрытые пути (`server/`, `data/`, `.git/`).
Не проверено: нагрузка на целый класс сразу и работа с планшетами и телефонами.

## Хостинг на своём VPS
Нужен Python 3 и обратный прокси (nginx или Caddy).

1. Скопируйте проект: `rsync -av --exclude .git --exclude data ./ user@server:/var/www/physlab/`
2. Сервис: `deploy/physlab.service` в `/etc/systemd/system/`, замените `TEACHER_KEY` на свой длинный ключ, затем `sudo systemctl enable --now physlab`.
3. Прокси: `deploy/nginx.conf` (или `deploy/Caddyfile`), домен замените на свой, HTTPS: `sudo certbot --nginx -d physlab.example.kz`.
4. Папка `data/` должна быть доступна для записи пользователю `www-data`.

Вариант в Docker: `docker build -f deploy/Dockerfile -t physlab . && docker run -p 8080:8080 -e TEACHER_KEY=секрет -v physlab-data:/app/data physlab`.
